
# 腾讯视频 ATCA 智能广告调度系统 - 交互式 Demo

## 🎯 项目概览
构建一个完整的可交互产品演示，用于展示腾讯视频 ATCA 中台的三大商业化广告模块及智能调度引擎，配套 KPI 数据看板。视觉采用腾讯视频品牌深色风（深空底 + 腾讯蓝 #0099FF + 活力橙 #FF6022 点缀）。

## 🧠 V1.1 升级：AI 内容理解层
在"环境调度引擎"之上新增 AI 内容感知层，解决三大痛点：
- 广告与剧情无关 → **Content-Relevance**：多模态识别剧集/人物/道具/情绪 → 推荐同源品牌
- 时机差·高潮硬切 → **Moment-Awareness**：情节张力曲线建模 → 仅低张力点插入
- 形式单一·硬塞 → **Format-Orchestration**：动态选择互动/浮层/VPP/跨端

链路：AI 内容理解 → 环境调度引擎 → 模块 A/B/C 创意编排 → 客户端下发

## 🗺️ 站点结构（5 个页面 + 顶部导航）

1. **首页 / 调度中台总览** `/`
   - Hero 区：ATCA 系统介绍 + 实时调度可视化动画
   - 三大模块入口卡片
   - 调度规则引擎流程图（环境参数 → 命中场景 → 下发策略）
   
2. **场景模拟器** `/simulator`
   - 用户调整环境参数（投屏开关、连播状态、视频时长、音频输出）
   - 实时显示规则引擎判定过程，命中哪个场景，下发哪个策略
   - 一键跳转到对应模块的 Demo

3. **模块 A Demo - AIGC 动态回顾** `/module-a`
   - 模拟"上一集播完 → 进入下一集"的连播体验
   - 播放器内：AI 混剪上集回顾视频 + 顶部品牌护航浮层
   - 右下角悬浮购物车 Icon → 点击弹出半屏小程序加购卡片
   - 右侧面板展示后台情绪标签打标过程

4. **模块 B Demo - 二选一互动竞价** `/module-b`（MVP 重点）
   - 视频开始前出现分屏 UI（左 30% 贴片 / 右 70% 答题）
   - 5 秒倒计时动画
   - 点击右侧 → 弹出选择题（剧中道具品牌识别）
   - 答对 → "获得免广告特权 + 微信卡包到账"飘字动效 → 切入正片
   - 倒计时结束未操作 → 默认走 60s 贴片逻辑
   - 侧栏：广告主题库配置预览

5. **模块 C Demo - 跨端 VPP 静默植入** `/module-c`
   - 左右双屏并排：左侧 TV 大屏 + 右侧 Mobile 手机
   - 点击"开始投屏" → 大屏秒播正片，特定时间戳出现 VPP 虚拟物品（高亮标识）
   - 大屏右下角"本集无贴片打扰"小字提示（5 秒消失）
   - 手机端同步弹出 In-App Banner："大屏免打扰已生效，赠 50 元代金券"
   - 展示云端视频流 + 跨端状态同步示意

6. **数据看板** `/dashboard`
   - 防御指标：广告时段流失率折线图、二选一放弃率
   - 进攻指标：CPE 趋势、CVR（A 加购率 / C 核销率）柱状图、ARPU 变动
   - 模块对比雷达图
   - 全部使用 recharts 模拟数据

## 🛠️ 技术实现要点

- React Router 配置 6 个路由
- 全局深色主题（更新 `index.css` 设计系统 + `tailwind.config.ts` 加入腾讯蓝/橙）
- 顶部统一导航栏（Logo + 模块切换 + 当前调度策略指示器）
- 使用 `framer-motion` 实现倒计时、飘字、流程图动画
- 使用 `recharts` 渲染数据看板
- 模块化组件：`<TencentPlayer>`、`<RuleEngineFlow>`、`<DualScreenSimulator>`、`<KPICard>`
